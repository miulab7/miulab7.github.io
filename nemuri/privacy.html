プライバシーポリシー

ytpub（眠りの周波数ラボの投稿ツール）　制定日：2026年10月19日

このツールについて

ytpub は、YouTubeチャンネル「眠りの周波数ラボ」の運営者が、自分のチャンネルを 運営するためだけに使う個人用のツールです。一般の利用者に提供するものではありません。

Googleから受け取る情報

運営者が自分のGoogleアカウントで許可したときに、次の権限を受け取ります。

  • YouTubeアカウントの管理（youtube・youtube.force-ssl）
  • YouTube Analytics の読み取り（yt-analytics.readonly）

使い道

  • 運営者自身のチャンネルへの動画の投稿と公開予約
  • 動画の情報（タイトル・説明・サムネイルなど）の設定と、再生リストへの追加
  • 運営者自身の動画へのコメントの投稿
  • 再生回数・視聴時間などの統計の読み取り（次の動画づくりの参考にするため）

これ以外の目的には使いません。

保存と共有

  • 認可の情報（トークン）は、運営者のコンピューターの中にだけ保存します。
  • 受け取った情報を、第三者へ提供・販売することはありません。
  • 広告や、利用者の行動を追跡する仕組みは使っていません。このサイトもCookieを使いません。

ytpub がGoogle APIから受け取った情報の利用と移転は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

YouTube API サービス

ytpub は YouTube API サービスを使っています。利用にあたっては YouTube 利用規約と Google プライバシーポリシーが適用されます。

許可の取り消し

許可は、Googleアカウントの サードパーティ製のアプリとサービス からいつでも取り消せます。

お問い合わせ

YouTubeチャンネル 眠りの周波数ラボ までお寄せください。
